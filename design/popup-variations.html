Ticker Transfer popup: four options

Each option shows the same two moments at real popup size (380 px wide): Export on a TradingView chart, and the Import preview on Zerodha Kite. All data is example data. Pick one, or mix parts of two.

Option A

Tabs and cards

A cleaner form of the popup you have now. Import and Export stay as two tabs. A status card shows the site, and three small counts give the summary.

  • Smallest change to the current code.
  • Familiar. Users of TickerDrop know this layout.
  • The raw list text takes a lot of space.
  • Groups show as plain rows, without the symbols.

Option B

Route from → to

No tabs. The top strip shows where the list comes from and where it goes. The popup knows the site of this tab, so it shows only the next step.

  • The user always sees the full move: source, list, target.
  • One main button for each screen. Hard to click the wrong thing.
  • The page panel (right) keeps the progress when the popup closes.
  • More new code. The popup needs a small state machine.

Option C

Trader terminal

Dense, dark and monospace, like a trading terminal. Symbols show as small chips. Skipped and failed symbols have their own marks. Dark only, by choice.

  • Most data in the smallest space.
  • Looks at home next to Kite and TradingView dark themes.
  • Less friendly for new users.
  • Keyboard hints must not use B or S (Kite order keys).

Option D

Sections first

The list itself is the main content. Each section is a row that opens to show its symbols. The actions sit in a fixed tray at the bottom.

  • Users check the symbols before they click Add.
  • Each section shows its target group in place.
  • The buttons stay in the same place on both tabs.
  • A long list (100+ symbols) needs scroll inside the popup.

All four options keep the same rules: the popup never opens the watchlist panel for you, and it never clicks Buy, Sell or any order control. Firefox popups follow the system theme, so options A, B and D have a light and a dark form. Change your system theme to see both.
