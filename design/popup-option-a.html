Ticker Transfer popup, option A

Every screen of the extension, drawn in the "tabs and cards" style. Each popup is at real size (380 px). The texts are the real messages from popup.js and import.js; the lists are example data.

New screens (the code does not have these yet)

  • List menu: the popup clicks only a list tab on the page. It uses the click guard, like every other click.
  • Undo and Retry: Undo removes only what this run added, and needs a second click. Retry runs only the failed symbols.
  • File import: .txt (TradingView or Chartink list) and .csv (Symbol column). The popup reads the file locally.
